# 艾诺迪亚4 QOL 模块

为《艾诺迪亚4》提供游戏体验优化功能。

## 功能

- **扩展背包**：增加 5 个背包，可与原版背包、商店和合成器互通。
- **堆叠上限提升**：可堆叠物品上限提高至 999。
- **存档管理器**：备份、恢复和删除存档。
- **自动出售**：按装备、宝石等规则自动筛选出售物品。
- **自定义合成**：添加自定义配方，简化宝石合成操作。
- **游戏操作与数据接口**：提供游戏数据查询和操作功能。
- **其他优化**：包括属性范围显示、世界传送、推怪、任务卡死修复及屏蔽支付弹窗等。

## 安装

1. 从 [GitHub Releases](https://github.com/chenxi-Eumenides/inotia4-qol-lsposed/releases) 下载模块 APK。
2. 安装模块，在 LSPosed 中启用，并将游戏添加到作用域。
3. 重启游戏。

也可下载免 root 集成包安装使用。

## 使用

在游戏主菜单的「更多游戏」中打开模块设置和功能。
