# 艾诺迪亚4 QOL 改动 LSPosed 模块

《艾诺迪亚4》（Inotia 4）的 LSPosed 模块，以 Xposed 形式注入游戏本体（游戏零修改），提供多项体验优化（QOL）改动，并把游戏运行时数据与操作通过 HTTP API 导出，供外部程序或 AI 读取与操控。

另提供免 root 的 NPatch 集成包。

> 请支持正版！《艾诺迪亚4》已上架 Steam。

## 功能

### 扩展背包

- 在原版背包之外新增 5 个扩展背包
- 支持拖放移动、同类合并
- 与商店、合成器互通：购买、出售、合成选材与产物入库均可使用扩展背包物品

### 堆叠上限提升

- 可堆叠物品的上限由 99 提升到 999

### 存档管理器

- 把原版存档与模块数据导出为 `.qol_save` 备份，并可导入到任意槽位
- 支持列表查看与删除；按内容校验去重
- 新版随存档一并包含 monster 个人仓库；旧版备份仍可读取

### 自动出售

- 规则（OR 逻辑）：
  - 装备·品质：出售品质 ≤ 所选档（白 / 绿 / 蓝 / 黄 / 紫）
  - 装备·强化耐久度：出售强化耐久度 ≤ 所选档
  - 装备·总孔数：出售总孔数 ≤ 所选档
  - 宝石·档位：出售宝石档位 ≤ 所选档（低级 / 中级 / 高级 / 顶级 / 混沌）
  - 宝石·属性范围：出售属性优良度百分位 ≤ 所选档（30 / 60 / 75 / 90 / 99）
  - 特殊类型：背包 / 英雄徽章 / 骰子
- 硬保护：不可售、任务袋、已穿戴、已强化、已镶嵌

### 自定义合成

- 允许自定义的配方合成
- 优化 3 个宝石合成高级宝石的操作：自动选中空槽、不用切换配方
- 添加了 1 个强化宝石的方式
- 有两个彩蛋配方

### HTTP API

- **数据导出 API**：读取运行时状态（血量、金币、等级、坐标、背包、装备、技能、佣兵等）与静态数据（数值表、道具、地图、文本等）
- **操作 API**：通过 API 触发移动、使用道具、装备、队伍等游戏内操作
- 越权类操作位于 `/api/op/*`，需在配置中开启（默认关闭）

### 其他零散功能

- **属性显示范围**：装备与宝石详情中的随机属性数值，按其可能取值范围内的百分位着色（金 ≥100%、紫 ≥90%、蓝 ≥75%、绿 ≥60%、白 ≥30%、灰 <30%）
- 更清晰可控的世界传送
- 角色面板属性汉化
- 任务完成卡死修复
- 屏蔽支付弹窗
- 主菜单「开始游戏」不再弹出 Com2uS Hive 注册/登录询问，直接进入存档选择
- 不起眼的水印，用于从截图识别是否安装了 QOL

## 安装

两种方式，任选其一。

### 方式一：LSPosed 模块（需 root）

1. 从 Releases 下载模块 APK（`inotia4_qol_lsposed_release_vX.Y.Z.apk`）。
2. 安装后在 LSPosed 中启用模块，作用域勾选游戏包名
   `com.com2us.inotia4.normal.freefull.google.global.android.common`。
3. 重启游戏。

### 方式二：免 root 集成包（NPatch）

1. 从 Releases 下载与你的游戏版本对应的 `*_npatched_v*.apk`。
2. 直接覆盖安装（改版与集成包同签名可直接覆盖；原版由 Com2us 签名，需先卸载原版，请注意备份存档）。
3. 启动游戏即可。

## 使用

- 游戏内：主菜单点击「更多游戏」，选择需要的功能打开。
- 存档管理器：主菜单「更多游戏」→「存档备份」，选槽导出/导入，右侧列表删除；导出文件位于
  `Android/data/com.com2us.inotia4.normal.freefull.google.global.android.common/files/save_backup`，
  用系统原生文件管理器打开该路径。
- HTTP API：模块启动后在本机 `http://<设备IP>:8088` 提供（局域网内可访问）。API 为明文 HTTP，仅建议在可信局域网内使用。
  - `docs/reference/api-reference.md` —— API 规格
  - `docs/guides/game-guide.md` —— 游玩与 API 操作手册
