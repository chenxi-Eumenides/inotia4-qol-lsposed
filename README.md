# 艾诺迪亚4 QOL 改动 LSPosed 模块

《艾诺迪亚4》（Inotia 4）的 LSPosed 模块，以 Xposed 形式注入游戏本体，提供多项体验优化改动。

另提供免 root 的 LSPatch 集成包。

> 请支持正版！《艾诺迪亚4》已上架 Steam。

## 功能

以下功能可自行选择开启/关闭

### 扩展背包

- 在原版背包之外新增扩展背包，数量在模块设置页选择（5–20，默认关闭）
- 配置文件中的 `bagCount` 可设为 0–128；超过 20 个的袋仍可经接口使用，页签最多显示 20 个（4 列 × 5 行）
- 支持商店、合成器页面
- 支持所有原版背包的操作
- 缩小数量不会清除袋内数据，重新扩大后数据恢复

### 堆叠上限提升

- 可堆叠物品的上限由 99 提升到 999

### 存档管理器

- 把原版存档与模块数据导出为 `.qol.bak` 备份
- 可跨设备、跨槽位导入备份
- 支持备份monster仓库、c18背包

### 自动出售

- 按规则自动出售背包中的物品
  - 装备品质： ≤ 白 / 绿 / 蓝 / 黄 / 紫
  - 装备强化耐久度： ≤ 所选档
  - 装备总孔数： ≤ 所选档
  - 宝石档位： ≤ 低级 / 中级 / 高级 / 顶级 / 混沌
  - 宝石属性范围： ≤ 30% / 60% / 75% / 90% / 99%
  - 背包： ≤ 手提包 / 小背包 / 中背包 / 大背包
  - 徽章： ≤ 佣兵徽章 / 被祝福的佣兵徽章 / 教团徽章 / 英雄徽章
  - 骰子： ≤ 低级骰子 / 中级骰子 / 高级骰子 / 混沌骰子
- 硬保护：不可售、任务袋、已穿戴、已强化、已镶嵌
- 右上角的x按一下变为✓启用

### 自定义合成

- 自动选中空槽、不用切换配方
- 允许自定义的配方合成
  - 3个同级宝石合成高一级宝石
  - 添加了 1 个强化宝石的方式
  - 槽1皮革，槽2空，槽3魔法布料：大背包
  - 有多个彩蛋配方

### 移动优化

- 可以 八向移动 / 全向移动
- 可以调整移动速度

### 世界调整

- 可以调整游戏的 经验倍率、金币倍率、敌怪血量倍率、伤害倍率、承伤倍率

### HTTP API

- 数据导出 API：
  - 读取运行时状态：血量、金币、等级、坐标、背包、装备、技能、佣兵等
  - 读取静态数据：数值表、道具、地图、文本等
- 操作 API：
  - 通过 API 触发移动、使用道具、装备、队伍等游戏内操作
- 越权类操作位于 `/api/op/*`，需在配置中开启（默认关闭）

### 其他零散功能

- 属性范围渲染
  - 装备/宝石的属性，会按取值范围内的百分位着色
  - 金 ≥100%、紫 ≥90%、蓝 ≥75%、绿 ≥60%、白 ≥30%、灰 <30%
- 更清晰可控的世界传送
- 合成器传送保底
  - 合成器任务给的套装，在没有全部获得前，不会重复获得
- 推怪
  - 可推开挡路的怪物 / 队友 / 召唤物
- 角色面板属性汉化
- 任务完成卡死修复
- 屏蔽各种弹窗
- QOL水印

## 安装

两种方式，任选其一。

### 方式一：LSPosed 模块（需 root）

1. 从 [Releases](https://github.com/chenxi-Eumenides/inotia4-qol-lsposed/releases) 下载模块 APK（`inotia4_qol_lsposed_release_vX.Y.Z.apk`）。
2. 安装后在 LSPosed 中启用模块，作用域勾选游戏的实际安装包名。默认推荐列表里是原版包名
   `com.com2us.inotia4.normal.freefull.google.global.android.common`；改过包名的版本直接勾选它自己的
   包名即可，无需重新构建模块。
3. 重启游戏。

### 方式二：免 root 集成包（LSPatch）

1. 从 [Releases](https://github.com/chenxi-Eumenides/inotia4-qol-lsposed/releases) 下载与你的游戏版本对应的 `*_lspatch.apk`。
2. 直接安装（与其他改版可覆盖安装）。
3. 启动游戏即可。

## 使用

- 主菜单点击齿轮图标，进入模块设置页
- 选择需要的功能打开。部分功能是**默认关闭**的
- 存档管理器
  - 点击选槽，箭头按钮导出/导入选中槽，X按钮删除选中槽/存档
  - 导出文件位于
  `Android/data/<游戏实际包名>/files/qol/backups`（原版包名为
  `com.com2us.inotia4.normal.freefull.google.global.android.common`），用系统原生文件管理器打开该路径
- HTTP API
  - 模块启动后在本机 `http://<设备IP>:8088` 提供（局域网内可访问）
  - API 为明文 HTTP，仅建议在可信局域网内使用
  - `docs/reference/api-reference.md` —— API 规格
  - `docs/guides/game-guide.md` —— 游玩与 API 操作手册
