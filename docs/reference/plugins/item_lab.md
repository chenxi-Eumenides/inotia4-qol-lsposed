# `item_lab` 物品构造测试

`item_lab.construct` 启用后，在背包页自动出售按钮左侧显示「造」按钮。点击一次会在当前原生背包中构造以下物品；若 slot 0 有物品，先复制一件到当前袋空槽并申请新 UID。

| 类型 | category | 数量 / 属性 |
|---|---:|---|
| 恢复药水（小） | 5 | count=7 |
| 高级宝石 | 30 | count=1，属性类型 0（力量），值 60 |
| 基础短剑 | 462 | count=1；原生词条 code/value：0/15、1/12、2/10；magic_rate=100、socket=0x30、enchant=0 |
| slot 0 副本（如有） | 源物品类别 | 源数量；UID 由游戏重新分配 |

装备 payload 解析预期：category bits=462、raw type=4、三个原生词条按表列值、总孔 3 且已镶 0。所有新物品由游戏分配 UID；日志域 `item_lab` 逐件记录预期值及实际 `space/bag/slot`。

插件在操作前检查当前袋剩余容量：slot 0 有物品需至少 4 个空位，否则至少 3 个。容量不足会 WARN 并跳过整批。当前袋 raw 值 0..4 映射原版袋，6..10 映射改版袋；5 或非法值回退原版袋 0 并 WARN。单件创建或落位失败会记录 WARN，不承诺跨物品回滚。

本插件仅供测试，避免在重要存档中使用。
