# `core.feature` 插件

`core.feature` 是迁移期的兼容功能插件：当前承载一条尚未实现的路由占位，以及一个用户可见的暴击特效屏蔽开关。

## 职责边界

| 拥有 | 不拥有 |
|---|---|
| 未实现路由 `POST /api/character/combat/{role}/set_skill_usage` 的 501 占位响应 | 战斗技能的真正实现（属于 `core.character` 领域） |
| 「屏蔽暴击特效」开关的运行时判定 | 暴击伤害计算、命中判定和伤害数字 |
| 暴击分支闪白、震屏、震动的拦截 | 其他来源的屏幕震动和设备震动 |

## 能力与开关

| feature id | 类型 | 默认 | 分类 | 行为 |
|---|---|---|---|---|
| `core.feature.mask_crit_effects` | toggle | 开启 | 基础优化 | 拦截暴击分支的全屏闪白、横向打击条、震屏和震动；保留暴击光效和伤害数字 |
| `core.feature.compatibility_routes` | toggle | 开启 | 隐藏 | 迁移占位路由的启用标记，不产生用户可见行为 |

「屏蔽暴击特效」只影响暴击命中时由游戏暴击分支添加的反馈：

- 拦截 `0x5a` 受击闪白；
- 拦截 `0x1f` 到 `0x22` 的横向蓝白打击条；
- 拦截同一暴击分支触发的屏幕震动；
- 拦截同一暴击分支触发的设备震动；
- 保留 `0x52`（物理）或 `0x1df`（法术）暴击光效；
- 保留伤害数字与其他战斗逻辑。

开关默认开启。关闭后，暴击反馈恢复原版行为。

## 公共契约

本插件不提供 capability 或 port，其他插件不能依赖其内部实现。

## HTTP surface

| 方法 | 路径 | 用途 | 成功响应 |
|---|---|---|---|
| POST | `/api/character/combat/{role}/set_skill_usage` | 迁移占位 | `501 {"ok":false,"error":"not implemented"}` |

该路由保留旧调用方兼容性，不代表技能设置已经实现。

## 状态与错误

- 插件未安装或未启用：路由返回 503。
- 路由已注册但未实现：返回 501，响应体固定。
- 暴击特效开关的持久化失败由 Host 配置事务处理；OpenCode 不感知失败细节。

## 线程与不变量

- HTTP handler 不访问游戏状态。
- 暴击特效判定发生在游戏主线程的伤害结算路径上，只读插件自身开关状态。
- 开关关闭时，所有被拦截的调用透传给原版函数。

实现细节见 [`core.feature-internals.md`](core.feature-internals.md)。
