# `move_merge`（已并入 `extension_bag`）

本插件的拖拽合并能力现由 [`extension_bag`](extension_bag.md) 持有：`ptrslot:MOVE_MERGE_GOT` 资源、`move_merge.drag_merge` feature（「拖动合并」，BasicOptimization、默认开启）与 `QOL_PORT_MOVE_MERGE` 端口均已迁入 `extension_bag`；原 `move_merge.control` 提供面已随之删除。

当前权威事实见 [`extension_bag`](extension_bag.md)。本文件仅保留历史入口，不再描述独立插件。
