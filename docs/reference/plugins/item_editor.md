# item_editor

`item_editor` 是仅显示的物品详情面板，入口位于背包页右上角自动出售按钮左侧。插件 feature `item_editor.panel` 默认关闭，且必须开启 OP 才能使用。

编辑阶段使用 `ItemEditorDraft` 内存镜像：进入面板时把当前物品快照复制到 draft，后续 UI 只读写 draft，不写实际物品。切换类别时以 `ITEMCLASSBASE` 类为单位，同类确认等价于取消；跨类必定丢弃具体 `item_id`，装备族之间保留前缀、词条、孔、强化、混沌和法伤率，装备族与物品族之间只保留数量，宝石属性只在宝石类内保留。实际提交接口尚未实现。

面板使用一个带装饰角的 60% 黑总底框；关闭按钮位于屏幕左上角。左侧保留一层自定义框，物品图标在框内水平居中，名称固定在图标下方；类别始终显示，支持堆叠的非装备物品显示数量，装备额外显示前缀、强化耐久度、总宝石孔数、伤害、防御、法伤、需要等级及混沌等级/数值率。各属性在可滚动的原生选项行中展示，按下显示金框。类别使用 `QolItemType` 中文名称及枚举 ID；装备类别若有子类静态文本也会显示。前缀根据物品稀有度和前缀类别生成，并显示 `raw:` 稀有度值。法伤按伤害乘魔法伤害倍率除以 100 计算，同时显示倍率。物品图标使用 `core.custom_ui` 的 `item_slot` 组件，格底来自游戏原生 `UI_003`（unit 15 loc 41，74×74），不采用自绘框。右侧始终显示三个标题，每段词条框数量对应只读数据中的实际数量，标题行不画背景；仅装备可用全部三段，宝石仅可用宝石词条段，其他类型的词条框灰显。宝石本体自身的宝石词条由 `jewel_attribute_type`/`jewel_value` 生成，不依赖空的 `jewel_options` 列表。装备词条数值的颜色通过 `attribute.quality` 查询并由 UI 适配器解析，与属性范围显示使用相同颜色；宝石、附魔词条和非装备不染色。词条数值按静态数据标记显示整数或一位小数百分比；未知名称显示“未知”，不推测名称。每个实际词条行右侧的 `×` 与标题行 `+` 同列对齐。数据只通过 `QOL_PORT_ITEM` 5.2 只读接口读取；装备详情通过 `UIDesc_GetData` 取当前物品对象，避免误用背包光标首格。没有有效选中物品时名称显示 `名称：`、类别显示 `类别：`，物品格内分两行显示“选择 / 物品”。

当前阶段不支持修改物品属性、选择、生成或删除词条。标题旁的 `+` 与词条行的 `×` 仅为界面占位，不触发操作。真机界面与图标绘制尚未验收，见 `VM-ITEM-EDITOR-01`。
