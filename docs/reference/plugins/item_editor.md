# item_editor

`item_editor` 是仅显示的物品详情面板，入口位于背包页右上角自动出售按钮左侧。插件 feature `item_editor.panel` 默认关闭，且必须开启 OP 才能使用。

编辑阶段使用 `ItemEditorDraft` 内存镜像：进入面板时把当前物品快照复制到 draft，后续 UI 只读写 draft，不写实际物品。点击“类别”打开类别卡片：36 个 `ITEMCLASSBASE` 类按武器/装备/物品三组、每行三列展示，可滚动；单选，再次点击取消，确认只改 draft，取消不改。同类确认等价于取消；跨类必定丢弃具体 `item_id`，装备族之间保留前缀、词条、孔、强化、混沌和法伤率，装备族与物品族之间只保留数量，宝石属性只在宝石类内保留。可堆叠的非装备类别可打开独立模态卡片临时调整数量：默认范围 1..99；`stack_limit.limit_999` 可用且启用时上限为 999，功能不可用或未启用时上限为 99。确认写入 draft，取消丢弃临时值。实际提交接口尚未实现。

面板使用一个带装饰角的 60% 黑总底框；关闭按钮位于屏幕左上角。左侧保留一层自定义框，物品图标在 74×74 格内按 64×64 范围居中，名称固定在图标下方；类别行固定在名称行下方、不参与滚动。未选择类别时，物品格灰显、名称行灰显，两者的点击回调都被拦截。非装备物品显示数量；可堆叠物品的数量行可打开 420×250 模态卡片，四列两行的增减按钮按 1、10、100、1000 调整并实时显示当前值，范围为 1..99；仅当 `stack_limit.limit_999` 可用且启用时上限为 999。不可堆叠物品的数量固定为 1，数量行灰显且不可点击。装备显示前缀、强化耐久度、总宝石孔数、非零伤害/防御/魔法攻击、需要等级及混沌等级/数值率。选择物品或确认前缀时通过 `QOL_PORT_ITEM` 5.5 的 `read_item_base_stats_ex` 按当前 raw rarity 读取并回填伤害、防御、魔法攻击倍率、需要等级和可堆叠标志；伤害/防御/需要等级由编码类型与类别表计算，魔法攻击倍率直接取 `ITEMCLASSBASE +0xB`（武器类固定值，防具/物品类为 0），不再创建临时物品；失败时保留 draft 当前值并记录结构化日志。各属性在可滚动的原生选项行中展示，key 左对齐、value 右对齐，按下显示金框。物品卡为四列布局（174×112 单元格、176 步长、760 宽卡片），候选按所需等级升序、同等级按 item_id 升序；装备候选名称附带所需等级，名称最多显示 8 个 UTF-8 codepoint，等级后缀保留。只绘制完整落在列表可视区内的槽位，避免越过确认/取消 footer。类别使用 `QolItemType` 中文名称及枚举 ID；装备类别直接显示子类名（如“双手武器”），不再显示“装备（双手武器）”。前缀行点击打开 760×400 选择卡片，不显示标题；raw 0..14 全部可选，按白/绿/蓝/黄/紫品质分组为五列，列宽 138、列间距 146；当前变种/类别没有对应名称的 raw 显示“无前缀”。C18 名称只出现在 C18 变种，其他变种不显示 C18 专属名称。确认只更新 draft，取消不改。物品格的品质角标由 raw 前缀映射，绘制游戏原生 unit 0x10 loc 5–8（绿/蓝/黄/紫；白色无原生角标）；物品卡中的候选物品不显示角标。魔法攻击数值按伤害乘魔法伤害倍率除以 100.0 计算并显示一位小数。物品图标使用 `core.custom_ui` 的 `item_slot` 组件，组件只接收物品 ID；格底来自游戏原生 `UI_003`（unit 15 loc 41，74×74），不采用自绘框。右侧始终显示三个标题，每段词条框数量对应只读数据中的实际数量，标题行不画背景；仅装备可用全部三段，宝石仅可用宝石词条段，其他类型的词条框灰显。宝石本体自身的宝石词条由 `jewel_attribute_type`/`jewel_value` 生成，不依赖空的 `jewel_options` 列表。装备词条数值的颜色通过 `attribute.quality` 查询并由 UI 适配器解析，与属性范围显示使用相同颜色；宝石、附魔词条和非装备不染色。词条数值按静态数据标记显示整数或一位小数百分比；未知名称显示“未知”，不推测名称。每个实际词条行右侧的 `×` 与标题行 `+` 同列对齐。装备详情通过 `UIDesc_GetData` 取当前物品对象，避免误用背包光标首格；静态数据与快照只读，不会修改实际物品。

当前阶段仅支持在 draft 中修改非装备物品数量，不支持修改其他物品属性、选择、生成或删除词条。标题旁的 `+` 与词条行的 `×` 仅为界面占位，不触发操作。真机界面与图标绘制尚未验收，见 `VM-ITEM-EDITOR-01`。
