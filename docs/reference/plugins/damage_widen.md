# `damage_widen` 插件

`damage_widen` 以 64 位中间乘积替换四条常用伤害公式，避免千分比定点运算在 32 位乘法处回绕。

## 职责边界

| 拥有 | 不拥有 |
|---|---|
| 普攻、普通魔攻、暴击增伤、魔法防御减伤的安全计算 | 技能倍率、持续伤害、物理防御及其他伤害路径 |

## 能力与开关

| ID | 默认值 | 用途 |
|---|---:|---|
| `damage_widen.enabled` | 开 | 启用四类常用伤害公式的安全计算 |

停用开关后恢复对应游戏原生 int32 数学；未能读取角色属性时也透传原函数。

## 覆盖范围

| 计算 | 行为 |
|---|---|
| 普通攻击伤害 | 使用 64 位中间乘积 |
| 普通魔法攻击伤害 | 使用 64 位中间乘积 |
| 暴击增伤 | 使用 64 位中间乘积 |
| 魔法防御减伤 | 使用 64 位中间乘积 |

## 公共契约

伤害结果限制在 `[0, INT32_MAX]`。负数钳制为 0 是预期的防崩行为；超过上限的结果钳制为 `2147483647`。

## 公共行为矩阵

| 条件 | 结果 |
|---|---|
| 插件开启且角色属性读面可用 | 四条公式使用 64 位乘积并钳制结果 |
| 插件关闭或属性读面不可用 | 调用对应原生函数 |
| 属性读取失败 | 该次调用整体透传原函数（原生 int32 数学），每条资源首次失败告警 |

## 线程与不变量

属性读面为只读直调，与原函数在被调线程上的自调用等价；不设主线程门禁，与 item 只读面同一纪律。
