# `damage_widen` 插件

`damage_widen` 以安全缩放、函数入口替换和指令级区域 trampoline 扩展伤害运算范围，避免关键路径的 32 位乘法回绕。

## 职责边界

| 拥有 | 不拥有 |
|---|---|
| 普攻/魔攻基础值、暴击、魔法与物理防御，以及已审计的普攻执行体和技能倍率乘点 | DOT、按类型技能分派与其他未审计伤害路径 |

## 能力与开关

| ID | 默认值 | 用途 |
|---|---:|---|
| `damage_widen.enabled` | 开 | 启用本插件声明的安全伤害计算与指令级守卫 |

停用开关后恢复对应游戏原生 int32 数学；未能读取角色属性时也透传原函数。

## 覆盖范围

| 计算 | 行为 |
|---|---|
| 普通攻击伤害 | 使用 64 位中间乘积 |
| 普通魔法攻击伤害 | 使用 64 位中间乘积 |
| 暴击增伤 | 使用 64 位中间乘积 |
| 魔法防御减伤 | 使用 64 位中间乘积 |
| `CHAR_Act_DD` | 5 个乘除区域使用安全缩放并钳制 |
| `CHAR_AttrAttackDamage` | 1 个倍率区域使用安全乘除 |
| `CHAR_CalcPhysicalDefense` | 保留动态 CAL 文本公式，宽化属性输入、减伤率和最终伤害计算 |

## 公共契约

伤害结果限制在 `[0, INT32_MAX]`。负数钳制为 0 是预期的防崩行为；超过上限的结果钳制为 `2147483647`。

## 公共行为矩阵

| 条件 | 结果 |
|---|---|
| 插件开启且角色属性读面可用 | 可用函数替换/区域守卫执行安全缩放并钳制结果 |
| 插件关闭或属性读面不可用 | 调用对应原生函数 |
| 属性读取失败 | 该次调用整体透传原函数（原生 int32 数学），每条资源首次失败告警 |

## 线程与不变量

属性读面为只读直调，与原函数在被调线程上的自调用等价；不设主线程门禁，与 item 只读面同一纪律。
