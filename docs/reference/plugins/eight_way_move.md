# `eight_way_move` 插件

触屏虚拟方向摇杆的八向移动增强。插件只接管方向触摸输入，不提供 HTTP 接口、capability 或可供其他插件调用的公共 API。

## 1. 定位与职责边界

| 拥有 | 不拥有 |
|---|---|
| 触屏方向摇杆的八向分类、斜向双箭头显示、斜向朝向保持 | 物理键盘、手柄或其他输入设备 |
| 玩家方向键分支的双轴移动增量 | 寻路/点击移动、AI 移动、推动规则本身 |
| 自身 feature 的启停与状态清理 | 地图、角色、物品、存档等领域数据 |

插件不改变原版四向移动链：行走动作、8px 转向闸门、切图检测、拾取、推动、动画仍由原版执行。

## 2. 能力与开关

| 项目 | 值 |
|---|---|
| 插件 id | `eight_way_move` |
| 插件版本 | `0.1.0` |
| 用户可见 feature | `eight_way_move.direction` |
| 默认值 | 关闭 |
| 分类 | Gameplay「更多优化功能」 |
| 类型 | toggle |
| Release 可见 | 是 |

没有 capability、HTTP 路由、JNI 绑定或公开命令。

## 3. 行为矩阵

| 输入 | 行为 |
|---|---|
| 上/下/左/右 | 与原版四向移动一致；只亮一个方向箭头 |
| 四个斜向 | 同时沿两个轴移动；原版主轴箭头 + 补画副轴箭头 |
| 斜向进入时的朝向 | 当前朝向属于该斜向两个轴时保持不变：右→右上/右下仍朝右，上→右上/左上仍朝上，左/下同理 |
| 斜向进入且当前朝向不属于该斜向两个轴 | 回退到主轴判定 |
| 中心死区 | 停止移动 |
| 松开/取消 | 停止移动，清理本功能写入的键码与按住状态 |
| 撞墙/撞单位 | 主轴失败立即停住；主轴成功后副轴被挡时保留主轴移动并做完整检查 |
| 斜向推动 | 不实现；斜向移动不会推动单位 |
| 切图/拾取/动画 | 由原版链执行一次，不因斜向翻倍 |

### 3.1 速度

两轴都使用完整 `delta`（8px → 8px），斜向总速度约为单轴的 `1.414` 倍。两轴 8px 保持原版 8px 对齐，避免方向切换或松手时触发 `CHAR_MoveOnWaitCoord` 补步；当前不做斜向降速。

### 3.2 全向移动

不支持。任意角度移动需要改变原版 `x&7/y&7` 转向闸门；本插件只提供八向。

## 4. 线程与不变量

- 所有输入与移动逻辑必须在游戏主线程执行。
- 插件仅在 Android 触屏虚拟摇杆模式下生效；虚拟摇杆不存在或非 Play 状态时不产生移动。
- 插件关闭后必须恢复原版四向行为，不留下自定义键码或按住状态。

## 5. 状态与错误

feature 关闭、资源不可用或插件安装失败时，本插件不改变移动行为。插件状态由 Host 生命周期与资源诊断面统一呈现，不额外定义用户可见错误码。

实现细节、资源列表、游戏函数地址和验证边界见 [`eight_way_move-internals.md`](eight_way_move-internals.md)。
