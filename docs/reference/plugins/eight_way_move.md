# `eight_way_move` 插件（八向/全向触屏移动）

触屏虚拟方向摇杆的主控角色移动模式选择。插件只接管方向触摸输入，不提供 HTTP 接口、capability 或可供其他插件调用的公共 API。

## 1. 定位与职责边界

| 拥有 | 不拥有 |
|---|---|
| 主控角色的八向与 44 方向全向触屏移动 | 物理键盘、手柄或其他输入设备 |
| 主控角色的 1px 坐标粒度、碰撞查询与补步取消 | AI 角色、队友的原版四向 8px 移动 |
| 主控切换时旧主控的 8px 吸附 | 寻路/点击移动、路径节点、推动规则本身 |
| 按已选格点方向显示旋转指针 | 地图、角色、物品、存档等领域数据 |

原版行走动作、切图检测、拾取、推动、动画仍由原版执行。**只有主控角色**可用本插件选择八向或全向移动；其他角色继续原版四向 8px 移动。

## 2. 能力与开关

| 项目 | 值 |
|---|---|
| 插件 id | `eight_way_move` |
| 插件版本 | `0.1.0` |
| 用户可见 feature | `eight_way_move.direction` |
| 类型/默认值 | choice / 关闭 |
| 分类 | Gameplay「更多优化功能」 |
| Release 可见 | 是 |

feature id 保持 `eight_way_move.direction`。choice 稳定值为 `eight_way`（「八向移动」）和 `omnidirectional`（「全向移动」）；Host 设置页的关闭项表示无 selection。已有旧 toggle 配置不迁移：没有 choice selection 的配置按关闭处理，即使旧 `features[eight_way_move.direction]` 曾为 `true` 也不会推导出模式。

Host 单 key 配置请求使用 `field="choice"`，`key` 为该 feature id，`value` 为以上稳定值；`null` 或空字符串关闭。例如 `{ "plugin_id":"eight_way_move", "field":"choice", "key":"eight_way_move.direction", "value":"eight_way" }`。

`QOL_PORT_MOVEMENT_INPUT` 升至 v1.2，尾追加 mode setter。旧 `set_enabled(true/false)` 保留 v1.1 语义：开启 44 方向全向、关闭移动模式。插件业务模式只由 Host choice callback 通知。

没有 capability、HTTP 路由、JNI 绑定或公开命令。

## 3. 行为矩阵

| 输入 | 行为 |
|---|---|
| 关闭 | 恢复原版四向输入，清理本功能键码/按住状态并吸附主控到 8px 瓦片中心 |
| 八向 | 从固定候选 `(±8,0)`、`(0,±8)`、`(±6,±6)` 中选择最近方向 |
| 全向 | 从原有 44 项 8px 中点圆候选表选择最近方向；表项、滞回与缩放保持不变 |
| 轴向/斜向 | 共用现有主副轴分解、`CHAR_Move` 顺序、碰撞查询、贴墙回退和 `delta/8` 缩放 |
| 模式切换 | 清空旧候选 index、selected 向量与输入状态，不跨候选表复用 index |
| 旋转指针 | 使用 `State.selected_dx/dy`（未缩放的整数候选向量），不使用原始触摸向量；释放、死区、关闭或零向量不绘制 |
| 近斜向朝向 | 当前朝向属于两个轴且分量接近时保持不变，减少方向翻转 |
| 中心死区 | 8px；停止移动 |
| 松开/取消 | 停止移动，隐藏旋转指针，清理本功能写入的键码、按住状态和等待位 |
| 撞墙/撞单位 | 主轴失败时回滚副轴并按完整模式滑行；两轴都失败则停住 |
| 推动 | 只走原版完整移动分支；不额外实现全向推动 |
| 切图/拾取/动画 | 由原版链执行一次，不因双轴翻倍 |
| 切角色 | 旧主控立即吸附到当前 16px 瓦片中心，再交给 AI |
### 3.1 速度

全向表项来自半径 8px 的中点圆：`(8,0) (8,1) (8,2) (7,3) (7,4) (6,5) (5,6) (4,7) (3,7) (2,8) (1,8) (0,8)` 的四象限镜像，共 44 个唯一方向。八向模式固定为轴向 8px 与对角 `(±6,±6)`。

- 单帧距离范围 7.62–8.25px，最大距离误差约 0.38px（4.8%）。
- 最大角度间隔约 10.4°，平均 7.5°。
- 1px 网格上除 4 条轴外没有精确 8px 的整数向量；45° 最近为 39.8°/50.2°，不做特殊 `(6,6)` 补偿。
- 速度 buff/debuff 改变 `delta` 时按 `delta/8` 缩放表项。
- 八向对角长度为 `sqrt(72)≈8.485px`，比轴向 8px 快约 6%；这是允许的整数落点取舍，不另加等速归一化。

### 3.2 全向移动

八向和全向模式均支持主控角色使用 1px 坐标粒度；其他角色仍走原版四向 8px。路径/AI 仍使用 8px 网格，`move_to` 从非 8px 坐标起手时可能先吸附 0–7px。

## 4. 线程与不变量

- 所有输入与移动逻辑必须在游戏主线程执行。
- 插件仅在 Android 触屏虚拟摇杆模式下生效；虚拟摇杆不存在或非 Play 状态时不产生移动。
- choice 关闭后必须恢复原版四向行为，不留下自定义键码、按住状态或非 8px 主控坐标；八向/全向切换清空旧候选状态。
- 只有 `ch == lead_member()` 的移动/补步走全向逻辑；其他角色调用原版路径。

## 5. 状态与错误

feature 关闭、资源不可用或插件安装失败时，本插件不改变移动行为。插件状态由 Host 生命周期与资源诊断面统一呈现，不额外定义用户可见错误码。

实现细节、资源列表、游戏函数地址和验证边界见 [`eight_way_move-internals.md`](eight_way_move-internals.md)。C18L v589 烟测已确认三态切换、重启恢复和 selected 高亮；撞墙、滑行、切图及其他分辨率仍未验收，完整状态为 `NOT_ACCEPTED`。
