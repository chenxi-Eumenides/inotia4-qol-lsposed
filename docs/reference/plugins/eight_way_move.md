# `eight_way_move` 插件（全向移动）

触屏虚拟方向摇杆的主控角色全向移动增强。插件只接管方向触摸输入，不提供 HTTP 接口、capability 或可供其他插件调用的公共 API。

## 1. 定位与职责边界

| 拥有 | 不拥有 |
|---|---|
| 主控角色的 44 方向 8px/帧全向移动 | 物理键盘、手柄或其他输入设备 |
| 主控角色的 1px 坐标粒度、碰撞查询与补步取消 | AI 角色、队友的原版四向 8px 移动 |
| 主控切换时旧主控的 8px 吸附 | 寻路/点击移动、路径节点、推动规则本身 |
| 原始触摸角度的旋转指针 | 地图、角色、物品、存档等领域数据 |

原版行走动作、切图检测、拾取、推动、动画仍由原版执行。**只有主控角色**走全向移动；其他角色继续原版四向 8px 移动。

## 2. 能力与开关

| 项目 | 值 |
|---|---|
| 插件 id | `eight_way_move` |
| 插件版本 | `0.1.0` |
| 用户可见 feature | `eight_way_move.direction` |
| 默认值 | 关闭 |
| 分类 | Gameplay「更多优化功能」 |
| 类型 | toggle |
| Release 可见 | 是 |

feature id 保持 `eight_way_move.direction` 以兼容已有配置；显示名称为「全向移动」，描述为「朝任何方向移动。」

没有 capability、HTTP 路由、JNI 绑定或公开命令。

## 3. 行为矩阵

| 输入 | 行为 |
|---|---|
| 任意方向 | 从 44 个 8px 圆格点中选择最近方向；单帧位移 7.62–8.25px |
| 轴向 | 与原版单轴移动一致；旋转指针指向该轴 |
| 斜向/任意角 | 主轴完整移动，副轴静默移动；隐藏原版四根固定箭头，用原版上箭头贴图按原始触摸角度旋转显示；松开/死区立即隐藏 |
| 近斜向朝向 | 当前朝向属于两个轴且分量接近时保持不变，减少方向翻转 |
| 中心死区 | 8px；停止移动 |
| 松开/取消 | 停止移动，隐藏旋转指针，清理本功能写入的键码、按住状态和等待位 |
| 撞墙/撞单位 | 主轴失败时回滚副轴并按完整模式滑行；两轴都失败则停住 |
| 推动 | 只走原版完整移动分支；不额外实现全向推动 |
| 切图/拾取/动画 | 由原版链执行一次，不因双轴翻倍 |
| 切角色 | 旧主控立即吸附到当前 16px 瓦片中心，再交给 AI |
| 关闭 feature | 当前主控吸附到瓦片中心后恢复原版四向行为 |

### 3.1 速度

表项来自半径 8px 的中点圆：`(8,0) (8,1) (8,2) (7,3) (7,4) (6,5) (5,6) (4,7) (3,7) (2,8) (1,8) (0,8)` 的四象限镜像，共 44 个唯一方向。

- 单帧距离范围 7.62–8.25px，最大距离误差约 0.38px（4.8%）。
- 最大角度间隔约 10.4°，平均 7.5°。
- 1px 网格上除 4 条轴外没有精确 8px 的整数向量；45° 最近为 39.8°/50.2°，不做特殊 `(6,6)` 补偿。
- 速度 buff/debuff 改变 `delta` 时按 `delta/8` 缩放表项。

### 3.2 全向移动

支持。主控角色使用 1px 坐标粒度；其他角色仍走原版四向 8px。路径/AI 仍使用 8px 网格，`move_to` 从非 8px 坐标起手时可能先吸附 0–7px。

## 4. 线程与不变量

- 所有输入与移动逻辑必须在游戏主线程执行。
- 插件仅在 Android 触屏虚拟摇杆模式下生效；虚拟摇杆不存在或非 Play 状态时不产生移动。
- 插件关闭后必须恢复原版四向行为，不留下自定义键码、按住状态或非 8px 主控坐标。
- 只有 `ch == lead_member()` 的移动/补步走全向逻辑；其他角色调用原版路径。

## 5. 状态与错误

feature 关闭、资源不可用或插件安装失败时，本插件不改变移动行为。插件状态由 Host 生命周期与资源诊断面统一呈现，不额外定义用户可见错误码。

实现细节、资源列表、游戏函数地址和验证边界见 [`eight_way_move-internals.md`](eight_way_move-internals.md)。
