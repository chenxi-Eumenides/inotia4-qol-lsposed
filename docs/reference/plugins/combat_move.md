# `combat_move` 插件

> **权威范围**：本文件是 `combat_move` 的用户可见行为与对外契约。内部实现、资源清单与地址证据见
> [`combat_move-internals.md`](combat_move-internals.md)。

## 1. 定位与职责边界

| 拥有 | 不拥有 |
|---|---|
| 出战主角自动攻击期间的攻击动作保持 | 移动速度、步长、八向/全向移动（`better_move`） |
| 移动到攻击目标范围外时的锁定解除 | 目标选择、索敌、仇恨计算 |
| 普攻出手前的攻击距离判定 | 技能施放、伤害与命中计算 |
| — | 佣兵/怪物/NPC 的战斗 AI |

## 2. 能力与开关

| Feature ID | 显示名称 | 默认 | 分类 | 类型 |
|---|---|---:|---|---|
| `combat_move.enabled` | 战斗优化 | 关闭 | Gameplay（更多优化功能） | toggle |

默认关闭。关闭时插件资源全部物理还原，游戏行为与原版一致。

## 3. 公共行为

开启后：

1. **移动不清除攻击锁定**：点击怪物进入自动攻击后，按方向键移动不会清空当前攻击目标。
2. **移动不替换攻击动作**：移动期间当前普攻动作不会被走路动作替换；角色坐标继续变化，攻击动作与其动画继续播放。
3. **出手前距离判定**：每次普攻动作即将开始时检查与当前目标的距离；超过“该普攻动作的攻击距离 + 余量”时，本次出手取消，但**不清除攻击目标**。目标回到范围内后自动继续攻击。
4. **余量随攻击范围递减**：攻击距离 4 时余量 +100%，距离 13 时余量 +10%，中间按线性递减；距离越远余量越少。
5. **其他清除时机不变**：目标死亡、切换地图、切换出战角色、主动停止战斗等原有清除路径保持原版行为。

作用范围仅限当前出战主角的普攻。技能动作、佣兵与怪物的战斗行为不受影响。

## 4. 边界与已知表现

- 引擎每个角色只有一个动作槽：移动期间播放的是攻击动画，不播放走路动画；表现为攻击动作伴随位移（脚部滑步属预期）。
- 方向变化且坐标未按 8px 对齐时，原版会有一到两帧原地转向；本插件不改变该行为。
- 距离判定发生在“出手前”：目标跨出范围时不会立即解除锁定，而是在下一次普攻开始时取消该次出手并保留锁定；回到范围内后继续攻击。
- 移动中攻击动作是否自动连段由原版动作链决定，本插件不额外驱动。

## 5. 线程与失败语义

- 所有判定与游戏调用都在游戏主线程的 hook 执行体内完成，不创建线程、不做跨线程等待。
- 资源安装失败按 fail-closed 处理并整组回滚；插件端口不可用或版本不匹配时插件安装失败，功能保持未启用。
- 插件停用/关闭时恢复原版函数入口与调用点，不保留残留状态。
