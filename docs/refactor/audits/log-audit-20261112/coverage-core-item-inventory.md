## 优先补全项

1. **补全 inventory action 的物品使用/丢弃最终失败**：覆盖 provider 与原生 action 共同路径，单次 W，带 `op`、bag/slot、item、`reason`；不新增成功 INFO。
2. **补齐拾取/容量拒绝结果**：只在最终入库失败处记录容量、数量与 `reason=inventory_full`；成功拾取若需要回放，仅在确认库存状态改变时 I。
3. **补齐 core.item 必需 hook 安装事务结果**：汇总成功/失败并携带失败 hook，区分功能整体不可用与单 hook 可降级；避免仅凭 backup 缺失事后发现问题。
4. **补齐背包扩容实际生效值**：在 capacity 变化时记录 `bag_limit` 与来源；不要记录每次查询/槽扫描。
5. **统一传输转换事务最终失败**：序列化、导入失败在最终边界一次 W，带 from/to/item/reason；rollback 失败保留 E，避免上下层重复报同一错误。
6. **给装备状态变更增加低频 INFO**：装备/卸下实际提交时一次 `apply` 事件；普通按钮调用与逐对象细节继续保持 D。
