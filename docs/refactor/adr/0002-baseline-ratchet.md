# ADR-0002：基线棘轮与临时豁免机制

- 状态：已采纳（2026-09-16）
- 关联：`scripts/maintenance/arch_baseline.json`、`arch_exemptions.json`、`ARCHITECTURE.md` §9.4

## 背景

重构起点存在大量存量违规（依赖方向、符号头越权、无法归属的资源安装点）。
若一次性要求全绿，重构无法开工；若只用「人工例外清单」，清单会失控并成为第二份事实源。

## 决策

1. **基线棘轮**：首次冻结存量违规（当前 124 条）到 `arch_baseline.json`；之后**新增违规即失败**，
   已消除条目在重新冻结时移除——基线只允许收缩，不允许扩张。
2. `--freeze` 按**规则前缀分区**更新，不允许覆盖其它脚本的条目；
   扩容基线必须使用 `--force-freeze` 并走评审（防止绕过棘轮）。
3. **临时豁免**（`arch_exemptions.json`）与基线分离：豁免是**有意保留**的例外，
   必须登记规则、路径、理由、批准范围、清除阶段、到期条件与**文档锚点**；无锚点视为未登记。
4. 结构事实（层分布、资源清单、JNI 面）由 `gen_baseline_doc.py` 生成 `docs/refactor/baseline.md`，
   支持 `--check` 在提交前校验其与磁盘一致。

## 后果

- 正向：重构可在既有债务上增量推进，且新增债务被机械阻止；豁免与债务语义分离，便于清零。
- 代价：每次有意变更若改变违规集合，需要显式冻结动作；`--check` 纳入提交前流程。
